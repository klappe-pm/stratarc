# Tutorials

Tutorials are lessons. Each one takes a reader who has not done the task before through it from start to finish, on one path, explaining only what that path needs. They exist so a newcomer succeeds at something real on the first try; they are not the place to look up options.

## Pages

- [Getting Started](getting-started.md): from an empty machine to an installed command, a scaffolded source root, one rule and a first deployment.
- [First Contribution](first-contribution.md): from a fresh clone to a passing test suite and a change ready for review.
