# How-To Guides

How-to guides are recipes. Each one solves a specific problem for a reader who already knows what Stratarc is and wants the steps, with the minimum of explanation along the way. They assume more than a tutorial and promise less: a guide gets you to one outcome and links to the reference for the details it skips.

## Set Up

- [Install](install.md): every supported way to install, upgrade and uninstall the command.
- [Configure Runtimes](configure-runtimes.md): choose which runtimes receive your configuration and where they live.
- [Migrate Existing Config](migrate-existing-config.md): bring a hand-maintained runtime directory under one source root.

## Author

- [Add a Rule](add-a-rule.md): write a standing instruction and choose who it applies to.
- [Add a Skill, Command or Agent](add-a-skill-command-or-agent.md): add the other shared items.
- [Add a Hook](add-a-hook.md): register a script that runs on a runtime event.
- [Set Up a Project](set-up-a-project.md): give one project its own instructions, rules and permissions.
- [Use the Control Plane](use-the-control-plane.md): read and edit the table that decides what reaches where.

## Operate

- [Preview and Deploy](preview-and-deploy.md): see a change before it lands, then deploy it.
- [Roll Back a Deploy](roll-back-a-deploy.md): verify a deploy and undo it when it does not match.
- [Troubleshooting](troubleshooting.md): known failure modes matched to their fixes.

## Extend

- [Add a Runtime](add-a-runtime.md): manage a runtime Stratarc does not ship with.

## Contribute
